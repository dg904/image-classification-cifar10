# CIFAR-10 Image Classification with CNN

A deep learning project that classifies images into 10 categories using a Convolutional Neural Network trained on the CIFAR-10 dataset.

## Final Test Accuracy: 74.84%

## What this project does
Takes an image and predicts whether it belongs to one of these 10 classes:
Plane, Car, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck

## What I used
- Python, TensorFlow, Keras
- 3-layer CNN with BatchNormalization and Dropout
- Data Augmentation to prevent overfitting
- EarlyStopping and ReduceLROnPlateau callbacks

## What I learned
Building this project gave me hands-on experience with real image data, understanding
how small changes like adding batch normalization or data augmentation can meaningfully
improve how well a model generalizes to unseen images.
